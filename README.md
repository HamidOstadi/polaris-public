## What Polaris Does

Polaris is a Chrome extension that gives you a complete analytical view of any X profile — without using X's API and without sending any data to external servers.

**Profile Intelligence**
- Follower, following, and post count tracking with change detection
- Account maturity metrics: age, posting rate, growth rate, follower-to-following ratio
- Plain-language profile summary
- Historical snapshots with delta indicators

**Tweet Analysis**
- Scrape and analyse up to 200 tweets per profile
- Content breakdown: originals, retweets, quotes, replies
- Engagement metrics: averages, medians, top-performing posts
- Posting patterns: day-of-week and hour-of-day activity
- Entity analysis: hashtags, mentions, linked domains, co-occurrence

**Analytics Dashboard**
- Full-page dashboard with sortable profile table
- Detailed profile view with stat tiles, charts, and tweet analysis
- Side-by-side profile comparison
- JSONL data export for further analysis

**Privacy by Design**
- All data stored locally in your browser (IndexedDB)
- Zero network requests — no analytics, no telemetry, no tracking
- No X API access — reads only what's publicly visible on the page
- Delete your data any time from the settings panel

## Install

Available on the [Chrome Web Store](https://chromewebstore.google.com/detail/polaris-%E2%80%94-x-profile-analy/amdkhhpfgdfflmmcnapcnkbhfeajgbkf).

For development:
1. Download or clone the extension files
2. Open `chrome://extensions/` in Chrome
3. Enable **Developer mode**
4. Click **Load unpacked** and select the extension folder

## Privacy

Polaris is built on a simple principle: your data belongs to you. Nothing leaves your browser — ever.
